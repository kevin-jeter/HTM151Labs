User Guide

Welcome to the HTM151: Nuvolo for Managers Labs! This guide is designed to help you navigate through the various labs included in this course. Each lab focuses on a specific aspect of using Nuvolo, providing hands-on experience and practical knowledge.

Getting Started

  1. Access Nuvolo Development Environment: Use the DEV environment for all labs. Login via https://vaoittrain.servicenowservices.com/ with your VA.gov account.
  2. Navigate This Guide: Use the dropdown menu above to select a specific lab. All sections include step-by-step instructions, screenshots, and interactive elements like input fields for answers.
  3. Theme Toggle: Switch between light and dark mode using the toggle in the top right for better readability.

Tips for Success

  • Explore Freely: Don't hesitate to click around Nuvolo—use the "History" tab to backtrack if needed. Avoid using your browser's back button, as it may not work well with Nuvolo.
  • Document Your Work: Many labs include input fields for recording answers (e.g., work order numbers). Use these to track your progress and share with instructors.
  • Troubleshooting: If you encounter issues, you're not alone! Ask your instructor(s) for help and you'll be helping out your peers too!
  • Practice Hypotheticals: Labs encourage creating hypothetical work orders and assets to build confidence without real-world consequences.

If you have questions, reach out to your instructor or refer to the course materials. Happy learning and mastering Nuvolo!

Happy learning!

Lab 1: HTM User Management

HTM User / Manager Setup

The Jonathan M Wainwright Memorial VA Medical Center at Walla Walla, WA has just gone on a mass hiring spree! The HTM department has benefited by onboarding many new employees across all job series and titles. These new HTM employees need to be granted access in Nuvolo to include the onboarding tasks detailed below.

  • All HTM employees must be added to the HTM WWW Biomedical group. Select HTM employees in supervisory roles must be additionally added to the HTM WWW Management group.
  • All HTM employees must be granted HTM User and/or HTM Manager access, as applicable.
  • All HTM Employees must have an internal rate configured.

Instructions:

As one of the HTM department’s Administrative Officers, you will find your employee on the spreadsheet in the chat and configure them in Nuvolo to grant them access as HTM Users and/or HTM Managers, where applicable.

Part 1: User Attributes

  1. Select All in the Filter Navigator. Type User in the search box and select Nuvolo User Attributes.
  2. Below the Nuvolo User Attributes list title, select the All link to remove default filters.
  3. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  4. In the Name column search box, type the employee’s first and last name and press Enter.
  5. Ensure the employee’s User ID (in parenthesis) matches the value on the spreadsheet and click the hyperlinked employee name to open the record.
  6. Search for and select Walla Walla, WA (WWW) for the Facility and Duty Station.
  7. Check the HTM User checkbox to grant employees access to Nuvolo. For supervisory employees, check the HTM Manager checkbox as well.
  8. Select the HTM Primary Role indicated on the spreadsheet.
  9. Click the Update to apply changes and close the record.

Part 2: Internal Rates

  1. Select All in the Filter Navigator. Type Rates in the search box and select Internal Employee Rates.
  2. Click the New button to generate an Internal Rates record.
  3. Click the Search button (magnifying glass) for the Employee field.
  4. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  5. Type the employee’s first and last name in their respective column search boxes and press enter.
  6. Ensure the employee’s User ID matches the value on the spreadsheet and click the hyperlinked employee’s first name.
  7. Search for and select Walla Walla, WA (WWW) for the Facility field.
  8. Select the Submit button to initially save the Internal Rates record.
  9. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  10. Type the employee’s first and last name in the Employee column search box and press Enter. Click the hyperlinked Yearly value ($0.00) to re-open the Internal Rates record.
  11. Using the spreadsheet, type or copy the corresponding Yearly and Hourly values into the Yearly and Labor Rate fields. Type or copy the Hourly value into the Travel Rate.
  12. Optionally, type or copy the corresponding Pay Plan, Classification Series, Grade, and Step values.
  13. Click the Update button to save changes and exit the Internal Rates record.

Optional: Technician Schedules

The Medical Center Director for the Jonathan M Wainwright Memorial VA Medical Center has implemented new operating hours for the facility. The facility will now to be open and will see Veterans Monday through Friday, 0700 to 1730, effective immediately. With so many HTM employees in the department, the Chief Biomedical Engineer has decided that employees will be divided into two shifts to allow coverage for the extended operating hours while minimizing Premium Pay costs.

  1. Shift A: Monday through Thursday, 0700 to 1730
  2. Shift B: Tuesday through Friday, 0700 to 1730

Nuvolo has already been configured to allow the automatic assignment of Clinical Work Orders to employees following Nuvolo’s Assignment Logic. To reflect the department’s transition to shifts, Clinical Technician Schedules will be entered in Nuvolo so the Nuvolo Assignment Logic will continue to assign Clinical Work Orders to only the employees present during the week, particularly on Mondays and Fridays.

INSTRUCTIONS: As one of the HTM department’s Administrative Officers, generate a Clinical Technician Schedule for your employee on the attached spreadsheet and configure their Schedule Entry to reflect the shift to which they are assigned.

Optional Part 1: Schedules

  1. Select All in the Filter Navigator. Type Schedule in the search box and select Technician Schedule.
  2. Click the New button to generate a Clinical Technician Schedules record.
  3. In the Technician field, click the Search button (magnifying glass).
  4. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  5. Type the employee’s first and last name in the search box and press Enter.
  6. Ensure the employee’s User ID matches the value on the spreadsheet and click the hyperlinked employee’s first name.
  7. Copy the selected Technician field value and paste it into the Name field.
  8. Select the Submit button to initially save the Clinical Technician Schedules record.
  9. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  10. Type the employee’s first and last name in the Employee column search box and press Enter. Click the hyperlinked Name to re-open the record.
  11. (As Applicable) Scroll to the bottom of the Group form and click Load Related Lists.
  12. Click the New button in the Schedule Entries tab to generate a new entry record.
  13. In the Name field, type A-Shift or B-Shift, as applicable. Ignore the Type and Show As fields.
  14. In the When section, check the All Day checkbox. Change both dates to September 30th of the current calendar year.
  15. In the Repeats field, select Specific. Leave the Repeats Every defaulted to 1 day.
  16. In the Repeats On field, check the days of the week the employee will be working and leave all other days unchecked.
    1. Shift A: Check Mon, Tues, Wed, Thu
    2. Shift B: Check Tues, Wed, Thu, Fri
  17. Click the Submit button to save the Schedule Entry.

Lab 2: Clinical Device Verifications

The Jonathan M Wainwright Memorial VA Medical Center at Walla Walla, WA has just opened its new multi-specialty inpatient hospital as part of a major activations project. Many Clinical Devices were purchased with activations funds and have been added to the facility’s inventory of record, AEMS/MERS, by Logistics.

The HTM department’s Administrative Officer has already assigned the new Equipment Records to an HTM Responsible Shop in AEMS/MERS and the corresponding Clinical Devices records have generated in Nuvolo by the Daily Device Feed; however, the new Clinical Devices need to “verified” and incoming inspection work orders generated.

INSTRUCTIONS: As an HTM Manager, you have been tasked to verify the assigned Clinical Devices indicated on the attached spreadsheet in Nuvolo and ensuring the incoming inspection work orders are generated.

Part 1: Navigation and Primary Data Fields

  1. Select All in the Filter Navigator. Type Unverified in the search box and select Unverified Devices (Pre-Validated).
  2. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  3. Type the Asset/EE# in the Asset Tag column search box and press Enter. Click the hyperlinked number to open the record.
  4. On the main Clinical Work Orders form, verify the following data fields are correct and update as needed.
    1. Asset Model Name: Ensure the model is correct and matches the spreadsheet.
    2. Operational Status. Ensure the Operational Status is Operational and not Non HTM Supported.
  5. Click on the Resources tab.

Part 2: Work Order Assignment

  1. In the Resources tab, verify and/or populate the following data fields.
    1. Support Group. Ensure the Support Group is set to HTM WWW Biomedical.
    2. Supported By. Search for an select your name as the Supported By.
  2. Optionally, in the Resources tab, populate the CM, PM, Cyber, and Other Support Group and Supported By data fields.
  3. Check the Verified checkbox.
  4. Click the Update or Save button.
  5. Ensure the new incoming inspection work order has been created banner displays.

Lab 3: Preventive Maintenance Definitions and Instances

The National PM Workgroup has issued a series of National OEM and AEM PM Standards to be implemented immediately for several Asset Types and Asset Model Names. To implement the National OEM and AEM Standards, Clinical Scheduled Maint Definitions will need to be created, configured, and activated.

INSTRUCTIONS: Using the attached spreadsheet, generate a Clinical Scheduled Maint Definition for the Asset Model Names previously updated, configure the PM definition accordingly, and, finally, activate the PM definition to generate the corresponding Clinical Scheduled Maintenances, or PM instances, for the affected Clinical Devices.

Part 1: Maintenance Definitions

  1. Select All in the Filter Navigator. Type Definitions in the search box and select 2. Maintenance Definitions.
  2. Click the New button to generate a new Clinical Scheduled Maint Definition record.
  3. Leave the Name field blank. This field will auto-populate when the PM definition is saved.
  4. In the Asset Conditions filters, apply the following changes, but leave the remaining values defaulted to their current values.
    1. Type the Asset Model Name value (or copy and paste) from the spreadsheet into the Asset Model Name ends with filter condition.
    2. Type the Asset Type (or copy and paste) from the spreadsheet into the Asset Type is filter condition.
  5. Click the Update Count (encircling arrows) button next to the No. of Records Matching the Condition. Ensure the updated count matches the Device Count from the spreadsheet.
  6. In the Schedule field, click the Search (magnifying glass) button and select the corresponding value from the spreadsheet.
  7. In the Work Order Type field, click the Search (magnifying glass) button and select the corresponding Type value from the spreadsheet.
  8. In the Start Date field, click the Select Date (calendar) button and select the corresponding value from the spreadsheet.
  9. In the Maintenance Source field, select the corresponding Standard Type value from the spreadsheet using Manufacturer for OEM.
  10. Type the WO Summary value (or copy and paste) from the spreadsheet into the Work Order Summary field. Replace the with the corresponding value the PM definition is being generated for.
  11. In the Asset Type field, type the corresponding value (or copy and paste) from the spreadsheet. When the Asset Types appear below the field, click the value to confirm the selection. If multiple correct values are present, select any of them.
  12. In the Model field, type the corresponding value (or copy and paste) from the spreadsheet. When the Asset Model Names appear below the field, click the correct value to confirm the selection. If multiple correct values are present, select any of them.
  13. Click the Save button to save changes to the PM definition.
  14. Ensure the Name field automatically populates.

Part 2: Activate

  1. Click the Activation button to activate the PM definition and generate the PM instances. In the confirmation dialog box, verify the count of PM instances to be created matches the Device Count from the spreadsheet and click OK.
  2. (As Applicable) Scroll to the bottom of the Clinical Scheduled Maint Definition form and click Load Related Lists.
  3. In the Clinical Scheduled Maintenances tab, ensure the count in the parenthesis matches the Device Count from the spreadsheet. If the number is too low, click the Save button again until the expected number is displayed.
  4. Verify that the PM instances Start Dates and the Asset Next Scheduled Maintenance dates populated according to the Start Date selected in the PM definition.
  5. [OPTIONAL] For any of the PM instances, double-click the Start Date value and select 08/01/2026. Click the Save button and verify the Start Date and Asset Next Scheduled Maintenance date fields updated to 08/01/2026.

Lab 4: YourHTM / VA-MDNS Model Matches

Recently, the VA-MDNS workgroup released a series of new Naming Standards to be implemented by the end of the quarter. The HTM department’s Administrative Officer has already implemented the required updates to the Equipment Records in AEMS/MERS, thus ensuring VA-MDNS compliance and conformance percentages are maintained.

The recent changes to the inventory data in AEMS/MERS; however, has created Asset Type and Asset Model Name mismatches in Nuvolo, a Tier 2 metric on the National KPI Scorecard. The Chief Biomedical Engineer has directed that the corresponding Clinical Device records be updated by the end of the quarter.

INSTRUCTIONS: Using the attached spreadsheet, make the necessary corrections to the assigned Clinical Device records in Nuvolo, indicated by the Current Model name.

Part 1: VA-MDNS

  1. Select All in the Filter Navigator. Type Devices in the search box and select My Facility Devices.
  2. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  3. Click the Column Options (three-dots) next to the Asset Tag column header and click Sort (A to Z).
  4. Type the Current Model value (or copy and paste) from the spreadsheet into the Asset Model Name column search box and press Enter.
  5. Ensure the count of results displayed matches the Device Count value from the spreadsheet.
  6. Open the first Clinical Devices record by clicking on the hyperlinked Asset Tag number.
  7. Click the Search button (magnifying glass) in the Asset Model Name data field.
  8. Type the Correct Model value (or copy and paste) from the spreadsheet into the Model Name column search box in the Models dialog box and press Enter.
  9. Ensure the correct model value displayed shows vamdns_guidance as the External Source.
  10. Select the corresponding Model Name value by clicking on the hyperlinked Number.
  11. Click Update to save changes to the first Clinical Devices record. Click Proceed Update to confirm the Asset Model Name change.
  12. Repeat steps 5 through 10 for the remaining Clinical Devices.
  13. When finished updating all affected Clinical Devices, double-click the Current Model value in the Asset Model Name column search box and press Backspace or Delete.
  14. Type the Correct Model value (or copy and paste) from the spreadsheet into the Asset Model Name column search box and press Enter.
  15. Ensure the count of results displayed matches the Device Count value from the spreadsheet.
