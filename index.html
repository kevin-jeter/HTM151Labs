User Guide

Welcome to the HTM151: Nuvolo for Managers Labs! This guide is designed to help you navigate through the various labs included in this course. Each lab focuses on a specific aspect of using Nuvolo, providing hands-on experience and practical knowledge.

Getting Started

  1. Access Nuvolo Development Environment: Use the DEV environment for all labs. Login via https://vasubprod1.servicenowservices.com/ with your VA.gov account.
  2. Navigate This Guide: Use the dropdown menu above to select a specific lab. All sections include step-by-step instructions, screenshots, and interactive elements like input fields for answers.
  3. Theme Toggle: Switch between light and dark mode using the toggle in the top right for better readability.

Tips for Success

  • Explore Freely: Don't hesitate to click around Nuvolo—use the "History" tab to backtrack if needed. Avoid using your browser's back button, as it may not work well with Nuvolo.
  • Document Your Work: Many labs include input fields for recording answers (e.g., work order numbers). Use these to track your progress and share with instructors.
  • Troubleshooting: If you encounter issues, you're not alone! Ask your instructor(s) for help and you'll be helping out your peers too!
  • Practice Hypotheticals: Labs encourage creating hypothetical work orders and assets to build confidence without real-world consequences.

If you have questions, reach out to your instructor or refer to the course materials. Happy learning and mastering Nuvolo!

Happy learning!

Lab 1: HTM User Management

HTM User / Manager Setup

The Jonathan M Wainwright Memorial VA Medical Center at Walla Walla, WA has just gone on a mass hiring spree! The HTM department has benefited by onboarding many new employees across all job series and titles. These new HTM employees need to be granted access in Nuvolo to include the onboarding tasks detailed below.

  • All HTM employees must be added to the HTM WWW Biomedical group. Select HTM employees in supervisory roles must be additionally added to the HTM WWW Management group.
  • All HTM employees must be granted HTM User and/or HTM Manager access, as applicable.
  • All HTM Employees must have an internal rate configured.

Instructions:

As one of the HTM department’s Administrative Officers, you will find your employee on the spreadsheet in the chat and configure them in Nuvolo to grant them access as HTM Users and/or HTM Managers, where applicable.

Part 1: Groups

  1. Select All in the Filter Navigator. Type Group in the search box and select Groups.
  2. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  3. In the Name column search box, type HTM WWW Biomedical and press Enter.
  4. Click the hyperlinked Group name to open the record.
  5. (As Applicable) Scroll to the bottom of the Group form and click Load Related Lists.
  6. Click on the Group Members tab. Click the Edit button to add employees to the Group.
  7. In the Edit Members screen, type the HTM employee’s first and last name in the Collection table’s search box. Ensure the employee’s User ID (in parenthesis) matches the value on the spreadsheet.
  8. Select the correct employee in the search results and click the Add button (>) to add them to the Group Members List.
  9. Click the Save button to save and exit the Edit Members screen. Click the Update button to exit the Group record.
  10. If the HTM employee is in a supervisory position, as indicated on the spreadsheet, repeat steps 2 through 7 using HTM WWW Management as the Group.

Part 2: User Attributes

  1. Select All in the Filter Navigator. Type User in the search box and select Nuvolo User Attributes.
  2. Below the Nuvolo User Attributes list title, select the All link to remove default filters.
  3. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  4. In the Name column search box, type the employee’s first and last name and press Enter.
  5. Ensure the employee’s User ID (in parenthesis) matches the value on the spreadsheet and click the hyperlinked employee name to open the record.
  6. Search for and select Walla Walla, WA (WWW) for the Facility and Duty Station.
  7. Check the HTM User checkbox to grant employees access to Nuvolo. For supervisory employees, check the HTM Manager checkbox as well.
  8. Select the HTM Primary Role indicated on the spreadsheet.
  9. Click the Update to apply changes and close the record.

Part 3: Internal Rates

  1. Select All in the Filter Navigator. Type Rates in the search box and select Internal Employee Rates.
  2. Click the New button to generate an Internal Rates record.
  3. Click the Search button (magnifying glass) for the Employee field.
  4. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  5. Type the employee’s first and last name in their respective column search boxes and press enter.
  6. Ensure the employee’s User ID matches the value on the spreadsheet and click the hyperlinked employee’s first name.
  7. Search for and select Walla Walla, WA (WWW) for the Facility field.
  8. Select the Submit button to initially save the Internal Rates record.
  9. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  10. Type the employee’s first and last name in the Employee column search box and press Enter. Click the hyperlinked Yearly value ($0.00) to re-open the Internal Rates record.
  11. Using the spreadsheet, type or copy the corresponding Yearly and Hourly values into the Yearly and Labor Rate fields. Type or copy the Hourly value into the Travel Rate.
  12. Optionally, type or copy the corresponding Pay Plan, Classification Series, Grade, and Step values.
  13. Click the Update button to save changes and exit the Internal Rates record.

Optional: Technician Schedules

The Medical Center Director for the Jonathan M Wainwright Memorial VA Medical Center has implemented new operating hours for the facility. The facility will now to be open and will see Veterans Monday through Friday, 0700 to 1730, effective immediately. With so many HTM employees in the department, the Chief Biomedical Engineer has decided that employees will be divided into two shifts to allow coverage for the extended operating hours while minimizing Premium Pay costs.

  1. Shift A: Monday through Thursday, 0700 to 1730
  2. Shift B: Tuesday through Friday, 0700 to 1730

Nuvolo has already been configured to allow the automatic assignment of Clinical Work Orders to employees following Nuvolo’s Assignment Logic. To reflect the department’s transition to shifts, Clinical Technician Schedules will be entered in Nuvolo so the Nuvolo Assignment Logic will continue to assign Clinical Work Orders to only the employees present during the week, particularly on Mondays and Fridays.

INSTRUCTIONS: As one of the HTM department’s Administrative Officers, generate a Clinical Technician Schedule for your employee on the attached spreadsheet and configure their Schedule Entry to reflect the shift to which they are assigned.

Optional Part 1: Schedules

  1. Select All in the Filter Navigator. Type Schedule in the search box and select Technician Schedule.
  2. Click the New button to generate a Clinical Technician Schedules record.
  3. In the Technician field, click the Search button (magnifying glass).
  4. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  5. Type the employee’s first and last name in the search box and press Enter.
  6. Ensure the employee’s User ID matches the value on the spreadsheet and click the hyperlinked employee’s first name.
  7. Copy the selected Technician field value and paste it into the Name field.
  8. Select the Submit button to initially save the Clinical Technician Schedules record.
  9. (As Applicable) Click the Show Column Search Row button (magnifying glass).
  10. Type the employee’s first and last name in the Employee column search box and press Enter. Click the hyperlinked Name to re-open the record.
  11. (As Applicable) Scroll to the bottom of the Group form and click Load Related Lists.
  12. Click the New button in the Schedule Entries tab to generate a new entry record.
  13. In the Name field, type A-Shift or B-Shift, as applicable. Ignore the Type and Show As fields.
  14. In the When section, check the All Day checkbox. Change both dates to September 30th of the current calendar year.
  15. In the Repeats field, select Specific. Leave the Repeats Every defaulted to 1 day.
  16. In the Repeats On field, check the days of the week the employee will be working and leave all other days unchecked.
    1. Shift A: Check Mon, Tues, Wed, Thu
    2. Shift B: Check Tues, Wed, Thu, Fri
  17. Click the Submit button to save the Schedule Entry.

Lab 2: Clinical Device Verification and Work Order Assignment

Part 1: Navigation and Primary Data Fields

  1. In the "All" filter navigator, search for "Unverified Devices" and select it. You may need to add "Verified" as a column to see the unverified devices.
  2. Click on the first Unverified Device to view its details. Hint: You must select the Asset Tag to open the device!
  3. Review the primary data fields on the device details page. Based on the information, answer the following questions:
    1. What is the device's serial number?
    2. What is the Operational Status of this device?
    3. Is there a Backup Available?
    4. Is this device a Loaner?
    5. What is the Warranty Expiration date?
    6. What is the PM Support Group?
    7. What was the last activity on this device?
    8. Is this device Cerner compatible?
  4. Before verifying this device, let's find out how to automatically assign groups for PM and CM Support on this device. Select the "Resources" tab.
  5. Let's update the PM Support Group. Select the "Eyeglass" icon next to the PM Support Group field.
  6. In the pop-up window, select one of the groups to give them automatic assignment to this device.
  7. Finally, let's verify this device. Select the "Verified" button and select Save.
  8. What time does the Daily Device Feed run every day?

    9. A: 2 AM EST

  9. Where is device data pulled from to the daily device feed?

    10. A: Device data is pulled from AEMS/MERS (VistA), Maximo, NMDD

  10. Where can you see the Daily Device Feed update history within a device record?

    11. A: Under the Activities tab at the bottom of the Clinical Devices record

Part 2: Work Order Assignment

We just used Automatic Assignment in the last lab, but how do we manage our groups and create new ones if we need to?

  1. In the "All" filter navigator, search for "Groups" and select it (Hint: It's the one under "Self Service")
  2. In the list, search for "HTM" followed by the HTM Program TLA (in this example, we use ABQ. Yours will be different!) and select Enter
  3. Select one of the groups.
  4. At the bottom of the page, you can select "Load Related Lists" to view additional details like Roles, Group Members, Groups, Skills, etc.
  5. Review the data fields and answer the following questions:
    1. What is the purpose/description of this group?
    2. How many Group Members are in this group?
    3. How many different Roles are assigned to this group?
    4. Is the group Active?
    5. What is the Group email?
  6. What is the role of the Group Manager in a Support Group?

    7. A: Typically the HTM Manager or department chief responsible for overseeing the group’s settings and performance

  7. What function does the Default Assignee serve in a Support Group?

    8. A: It determines the automatically assigned technician if no specific Supported By person is listed on the device

  8. Why is accurate group membership critical for automatic assignment?

    9. A: Nuvolo uses Support Group membership to route CM, PM, Cyber, and Other work orders to the correct personnel

  9. Why should you check your technician’s schedule before relying on automatic assignment?

    10. A: Because automatic assignment only works when a technician has an active schedule; otherwise, work orders default to the group instead.

Lab 3: Preventive Maintenance Definitions

A key aspect of PMs is PM definitions. This is how PMs will be auto-generated within Nuvolo. For this lab, we'll focus on creating a PM definition for "PALMSAT 2500A"

Part 1: Maintenance Definitions and Automatic Creation

  1. In the "All" filter navigator, search for "Maintenance Definitions" and select it.
  2. Select "New" to create a new PM Definition.
  3. Fill out the following fields:
    • Name: Leave this blank! Nuvolo automatically generates the name based on the other fields.
    • VISN: VISN 20
    • Facility: Walla Walla, WA
    • Model Name: ends with PALMSAT 2500A
    • Status: In Use, Loaned Out, Out of Service
    • Operational Status: is not NONE
  4. Scroll down for the next section to fill out. Follow the screenshot below for all fields:
  5. Select "Save" or "Submit" to complete the PM Definition creation.
  6. Let's find your PM Definition in the list. One of the easiest ways to do so is by editing your columns and searching by "Created by"
    • Select the gear icon in the top right corner of the list view
    • Search for "Created by" and add it to your selected columns
    • In the column Search, type "*" and your Last Name to find your PM Definition
  7. Select your newly created definition by clicking on the name
  8. Confirm the PM Definition is activated. If it isn't, click "Activate" in the top right corner.
  9. Why won’t Clinical Scheduled Maintenances appear before clicking Activate?

    10. A: Can only be generated only after the definition is activated.

  10. Where do you see the number of matching assets for your conditions?

    11. A: In the Asset Conditions in the link: No. of records matching the conditions

  11. What are the two related lists you should verify after activation?

    12. A: Maintenance Instance and Upcoming Scheduled Maintenance in Load Related List

Part 2: Generate Now (Ad Hoc Generation)

If a new asset/model has no existing definition, set Generation Type to Generate Now to create a work order

  1. Renavigate to the "Maintenance Definitions" main page.
  2. Select "New" to create a new PM Definition.
  3. Fill out the following fields:
    • Name: Leave this blank! Nuvolo automatically generates the name based on the other fields.
    • VISN: VISN 20
    • Facility: Walla Walla, WA
    • Model Name: ends with PALMSAT 2500A
    • Status: In Use, Loaned Out, Out of Service
    • Operational Status: is not NONE
  4. In the below section, select "Generate Now" in Generation Type. Note that Start Date is greyed out when it's selected.
  5. Select "Save" or "Submit" to complete the PM Definition creation.
  6. Does Generate Now create PM orders immediately?

    7. A: No – it is generated overnight.

  7. When should you switch back to Recurring after Generate Now?

    8. A: After initial PM work orders are generated (so the definition resumes scheduled recurring generation)
